# AI Companion

Браузерный прототип виртуального компаньона. Текущая версия: **v1.6 — Expressive Animation + Yandex AI bridge + device auth foundation**.

## Быстрый запуск (Windows)
1. Скачайте репозиторий или ZIP-архив.
2. Распакуйте файлы в одну папку.
3. Запустите `Запустить_AI_Companion.bat`.

## Файлы
- `AI_Companion_Emotional_Engine.html` — основной браузерный симулятор.
- `Запустить_AI_Companion.bat` — запуск в браузере Windows.
- `backend/` — облачный сервер понимания речи и авторизации устройств (v1.6), по умолчанию использует Yandex AI Studio API и подключается к браузерному симулятору.

## Что реализовано
- Отдельная звуковая лаборатория удалена из интерфейса: компаньон сам выбирает звук при реакции.
- Для 35 эмоций и 8 действий предусмотрены отдельные наборы по 50 процедурных звуковых вариантов.
- Эмоция связана со своим звуковым ключом, а не только с общей формой глаз.
- Разделены краткая эмоция и внутреннее состояние; реализован возврат к базовому состоянию.
- Потребности: энергия, любопытство, желание общения и комфорт.
- Взаимодействия: поглаживание, зов, удивление, игра, сон и пробуждение.
- У каждого действия свой характер звуковой реакции.
- Локальная память отношений: опыт, повторяющиеся действия, уровень связи и первые поведенческие привычки.
- Память хранится в браузере через localStorage на конкретном устройстве.
- Самостоятельные инициативы зависят от потребностей, темперамента и выбранной инициативности.
- Добавлено направление взгляда, микродвижения глаз и асимметричное моргание.
- Личностные привычки формируются по частоте поглаживаний, игр, зовов и отдыха; эти привычки влияют на инициативное поведение.
- Добавлен режим времени суток: утро, день, вечер и ночь; ночное поведение учитывает потребность в энергии.
- Разделены ручной сон и автономный сон: вручную уложенный компаньон ждёт пробуждения владельцем, а после самостоятельного отдыха может проснуться сам.
- Добавлено голосовое управление на русском через Web Speech API: владелец включает микрофон, произносит имя компаньона, после чего тот откликается и обрабатывает поддерживаемые просьбы.
- Имя владельца сохраняется локально в браузере; распознавание имени учитывает часть вариантов произношения латинских имён.
- Расширен разбор естественных русских формулировок: сон, пробуждение, игра, ласка, удивление, внимание, зов, приветствие, благодарность, радость, любопытство и эмоциональная поддержка.
- Добавлены голосовые информационные запросы («что ты умеешь», «повтори») и уточнение неоднозначных фраз.
- Поддерживаются дополнительные варианты произношения имени, задаваемые владельцем через запятую.
- Добавлена реакция на длительное удержание пальца на лице: отличает короткое касание от долгого нежного контакта.
- Контекст обращения сохраняется на короткое время, чтобы после имени можно было произнести просьбу отдельной фразой.
- AMOLED-концепция: чёрный фон и белые глаза.

- Добавлен переключатель облачного интеллекта в симуляторе: незнакомые голосовые фразы отправляются в защищённый backend Yandex AI Studio; API-ключ не попадает в браузер.
- Сначала выполняется локальный разбор команд, затем при необходимости — облачная интерпретация. При недоступности backend сохраняется локальное поведение.
- Настраивается адрес backend; по умолчанию для разработки используется `http://127.0.0.1:8787`.
\n- Backend v1.6: добавлена серверная регистрация устройств через доверенный enrollment secret и отдельный endpoint AI для устройств с индивидуальным Bearer-токеном. Токены хранятся в БД в виде хешей; открытый dev endpoint отключается при `APP_ENV=production`.
\n## Ограничения текущей версии
Звуки синтезируются через Web Audio API и не являются готовыми записями. Их качество необходимо оценивать на слух. Память и имя пока локальные и не синхронизируются между браузером, устройством и облаком. Анимация взгляда — ранний прототип, а не готовая аппаратная графика. Голосовое распознавание зависит от поддержки Web Speech API конкретным браузером (в первую очередь актуальные Chrome/Edge), разрешения микрофона и доступности сервиса распознавания. В зависимости от браузера аудио может обрабатываться его внешним сервисом; это не автономное офлайн-распознавание. Сейчас реализовано распознавание имени, вариантов произношения и набора команд/намерений с коротким контекстом, а не полное понимание произвольной речи или свободный диалог. Выражение грусти в браузерной версии дополнительно усилено визуально: опущенные глаза, брови и уголки рта, а также слеза. Разбор фраз основан на локальных правилах и ключевых выражениях, поэтому сложные, двусмысленные или незнакомые формулировки могут быть поняты неправильно. Долгое прикосновение в браузерной версии моделируется удержанием указателя на лице; это не проверка аппаратного сенсора. Сам компаньон не использует TTS и не отвечает человеческим голосом.

## Целевое устройство и ограничения
Целевая плата: **Waveshare ESP32-S3-Touch-AMOLED-1.75C**. Это браузерный прототип, не прошитый и не проверенный на физическом устройстве. Симулятор не подтверждает FPS, энергопотребление, тепловой режим или качество встроенного динамика.
