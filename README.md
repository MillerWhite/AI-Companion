# AI Companion

**AI Companion — электронный друг в компактном AMOLED-брелоке на Waveshare ESP32-S3-Touch-AMOLED-1.75C.** Это не тамагочи: в продукте нет голода, кормления или обязательного ухода. Основа — выразительный характер, локальные реакции, полезные инструменты и связь с телефоном/компьютером.

**Панель устройства:** https://millerwhite.github.io/AI-Companion/

## Что уже есть в репозитории

- Браузерная консоль с тёмным интерфейсом: подключение USB Serial/JTAG, чтение конфигурации и статуса, сохранение поддерживаемых настроек.
- Имя, темперамент, инициативность и черта характера с сохранением в NVS.
- Яркость, тема, таймаут сна, имя владельца, подпись и четыре строки Quick QR в рамках текущего USB-протокола.
- Быстрые реакции, доступные текущей прошивке: приветствие, отклик на владельца, сон/пробуждение и звук.
- Браузерные таймер и секундомер.
- Основа прошивки ESP-IDF для дисплея, эмоций, аудио, микрофона, датчиков движения, питания, Wi-Fi и USB.
- Backend для опционального распознавания речи и ограниченного понимания команд. API-ключи остаются на сервере.

## Продуктовый принцип

**Local-first.** Друг должен работать без интернета. Облачный AI — необязательное расширение, а не центральный интерфейс. Действия, эмоции и повседневные реакции принадлежат локальной прошивке.

## Что ещё не следует считать готовым

Панель честно показывает статус незавершённых аппаратных интеграций. В частности, текущая прошивка ещё не предоставляет законченные BLE-профили iPhone ANCS/AMS и HID для компьютера, QR-рендерер и навигацию по приложениям на круглом дисплее, шумомер/фонарик/игры на устройстве, а также законченный набор системных приложений. Эти функции нельзя считать реализованными только потому, что они отображаются в концепции или панели.

Нет подтверждённого успешного полного ESP-IDF build + физического теста на Waveshare. Плата ещё не прошла проверку в реальном корпусе. Публичный бинарный релиз прошивки также должен быть собран и опубликован перед использованием веб-установщика.

Подробная граница реализации и план — [docs/PRODUCT_DIRECTION.md](docs/PRODUCT_DIRECTION.md) и [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md).

## Запуск backend локально

Из корня репозитория:

```bash
python -m pip install -r backend/requirements.txt
cp backend/.env.example backend/.env
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8787
python -m unittest discover -s backend/tests -v
```

Никогда не помещайте API keys в HTML, firmware или GitHub. Секреты провайдера должны храниться только на backend. Любой ключ, ранее раскрытый в переписке или коммите, необходимо отозвать и заменить.

## Firmware

Сборка: см. [firmware/esp-idf/README.md](firmware/esp-idf/README.md). Веб-панель использует Chrome/Edge Web Serial API и USB-кабель с передачей данных. Не прошивайте устройство, пока workflow сборки не завершился успешно и GitHub Releases не содержит проверенный бинарный файл.

## Аппаратная платформа

- Waveshare ESP32-S3-Touch-AMOLED-1.75C
- ESP32-S3, круглый AMOLED, touch, IMU, аудиокодек и power-management IC

Любые заявления о работе датчиков, качестве звука, автономности, Bluetooth или производительности требуют проверки на физической плате.
