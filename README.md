# AI Companion

Браузерный прототип виртуального компаньона. Текущая версия: **v0.4**.

## Быстрый запуск (Windows)
1. Скачайте репозиторий или ZIP-архив.
2. Распакуйте файлы в одну папку.
3. Запустите `Запустить_AI_Companion.bat`.

BAT-файл пытается открыть HTML напрямую в Microsoft Edge или Google Chrome. Если они не найдены в стандартных местах, используется системная ассоциация HTML.

## Файлы
- `AI_Companion_Emotional_Engine.html` — основной браузерный симулятор.
- `Запустить_AI_Companion.bat` — запуск в браузере Windows.

## Статус
Это именно браузерный прототип. Он не прошит в плату и не подтверждён на физическом устройстве. Целевая плата проекта: Waveshare ESP32-S3-Touch-AMOLED-1.75C.

## Звуки
В v0.4 снижена громкость процедурных звуков, добавлен низкочастотный фильтр и более мягкое затухание. Автоматические звуковые инициативы стали реже. Это первая итерация настройки — субъективное качество звучания нужно проверить на компьютере и доработать по отзывам.
