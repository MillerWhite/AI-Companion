# AI Companion — продуктовая архитектура

## Позиционирование

AI Companion — электронный друг и карманная персональная консоль, не тамагочи. Не использовать голод, кормление, гигиену или обязательный уход как центральные механики. Устройство может само проявлять инициативу, замечать контекст и выражать эмоции, но не должно создавать чувство вины или требовать обслуживания.

## Архитектурные правила

1. **Локальное ядро:** лицо, эмоции, реакции на touch/IMU/mic/power, таймеры, приложения и базовое поведение работают на ESP32-S3 без сети.
2. **Опциональный AI:** облако вызывается только для сложного распознавания естественной речи. При ошибке сети устройство продолжает работать локально.
3. **Прямое подключение:** панель браузера управляет устройством через Web Serial; BLE появится только после реализации и тестирования соответствующих GATT/HID/ANCS/AMS сервисов в прошивке.
4. **Без ложных статусов:** наличие карточки или пункта меню не означает, что функция работает на устройстве. Все модули должны иметь статус implemented / partial / planned и критерии приёмки.
5. **Без секретов на клиенте:** ключи AI/Speech провайдеров не помещать в HTML, manifest или firmware.

## Функциональная карта

| Модуль | Текущее состояние по коду | Что требуется до готовности |
|---|---|---|
| USB Serial/JTAG консоль | Реализована базовая связь и чтение конфигурации/статуса | Тест соединения на целевой плате и обработка reconnect |
| Имя и характер | NVS поля темперамент/инициатива/черта | Проверить, что все поля реально влияют на поведение, экспорт/сброс профиля |
| Экран | Яркость, тема, sleep timeout через USB | Проверить реальные значения, пробуждение, батарейные режимы |
| Бейдж владельца | Хранение owner/badge в NVS | Рендеринг на дисплее и визуальная проверка |
| Quick QR | Хранение четырёх строк в NVS | QR encoder, экранное приложение, свайп/кнопочная навигация, иконки сервисов |
| Эмоции и характер | Есть программная основа | Полный переход на friend-модель без тамагочи-потребностей, длительное тестирование |
| Датчики | Есть программные модули движения, звука и питания | Калибровка, физические тесты, пороги и ложные срабатывания |
| Звуки | Есть программная основа аудио | Измерение громкости, качество, latency, тест микрофона/динамика |
| iPhone notifications | Не завершено | BLE ANCS, privacy modes, pairing UX, тест iOS |
| iPhone music/camera | Не завершено | BLE AMS/HID, команды управления, тест iOS |
| PC presentation remote | Не завершено | BLE HID keyboard/mouse, кнопки, наклон/указка, тест Windows/macOS/Linux |
| Apps: clock/timer/stopwatch/flashlight/noise meter | Не завершены на устройстве | UI-модули LVGL, события, энергопотребление |
| Игровые режимы | Не входят в продуктовую концепцию | AI Companion — компаньон, а не игровая приставка; оставить только полезные приложения и естественные реакции |
| Firmware installer | Есть manifest и ESP Web Tools оболочка | Успешный firmware build, tagged release asset, USB flash acceptance |
| Browser timer/stopwatch | Работают в web console | Не требуют прошивки |
| Cloud speech/intent | Backend и firmware path как основа | Проверить live credentials, безопасность, latency, квоты и отказоустойчивость |

## План приёмки

### A. Панель
- Chrome/Edge, USB connect/disconnect/reconnect.
- Конфигурация загружается из NVS; изменения сохраняются после отключения и перезагрузки.
- Все поля валидируются по диапазонам firmware.
- Никаких команд, отсутствующих в USB-протоколе.

### B. Firmware core
- ESP-IDF build green.
- UI и сенсоры работают без Wi-Fi.
- Лицо/эмоции не блокируют системные задачи.
- Питание, сон, пробуждение и зарядка измерены на целевой плате.

### C. Phone + computer
- iOS ANCS/AMS и BLE HID реализованы и проверены на реальных устройствах.
- Приватность уведомлений по умолчанию скрывает текст.
- Компьютерный HID не ломает существующее сопряжение с iPhone.

### D. On-device apps
- QR, бейдж, clock, timer, stopwatch, flashlight и noise meter имеют реальные LVGL экраны.
- Вход/выход из приложения, back/home, энергосбережение и восстановление состояния протестированы.

### E. Release
- Firmware CI successful.
- Tagged release с бинарником и checksum.
- Веб-прошивальщик проверен на реальной плате.
- Только после этого функция обновления считается готовой.

## Ограничения текущей поставки

Нынешний редизайн панели — рабочая web-консоль для уже поддерживаемого USB-протокола плюс браузерные инструменты. Он не заменяет отсутствующие BLE-сервисы, экранные приложения или физические тесты. Не считать весь список функций выше готовым до прохождения соответствующих критериев.
