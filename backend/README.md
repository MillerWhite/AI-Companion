# AI Companion — Language Backend v1.2

Отдельный сервер для понимания свободной речи. По умолчанию использует **Ollama с локальной моделью Qwen 3.5 4B**: API-ключ не нужен, запросы не тарифицируются внешним провайдером. Сервер не управляет экраном, динамиком, датчиками или прошивкой напрямую.

## 1. Установить Ollama и модель

1. Установите Ollama для Windows: https://ollama.com/download
2. Откройте PowerShell и выполните:

```powershell
ollama pull qwen3.5:4b
```

Модель занимает примерно 3.3–4.0 GB на диске. Если компьютеру тяжело, попробуйте меньшую модель:

```powershell
ollama pull qwen3.5:2b
```

В этом случае измените `AI_MODEL=qwen3.5:2b` в `backend\\.env`. Скорость зависит от процессора, оперативной памяти и видеокарты.

## 2. Установить и запустить backend

Требуется Python 3.10+.

Из корня репозитория в PowerShell:

```powershell
py -m venv backend\\.venv
backend\\.venv\\Scripts\\Activate.ps1
py -m pip install -r backend\\requirements.txt
Copy-Item backend\\.env.example backend\\.env
uvicorn backend.main:app --host 127.0.0.1 --port 8787
```

По умолчанию `.env.example` уже настроен на локальный Ollama. **Никакой API-ключ создавать или покупать не нужно.** Ollama должен быть запущен; приложение Ollama обычно работает в фоне после установки.

Проверка: откройте http://127.0.0.1:8787/health. Для проверки самой модели: `ollama list`.

## 3. API

`POST /api/interpret` принимает текстовую реплику и возвращает ограниченный JSON: `intent`, `action`, `emotion`, `confidence`, `nonverbal_cue`, `clarification`. Действия и эмоции проверяются по allowlist. Клиент обязан дополнительно проверить ответ и применить его через локальный движок.

## 4. Другой провайдер

Backend поддерживает OpenAI-compatible endpoint. Для удалённого провайдера установите `AI_PROVIDER=openai_compatible`, его URL, модель и ключ в `.env`. Удалённый сервис может иметь лимиты и плату. Не помещайте ключ в HTML и не публикуйте `.env`.

## 5. Ограничения и приватность

- Локальная модель не имеет внешнего лимита запросов, но ограничена производительностью компьютера, памятью, температурой и доступным местом на диске.
- Запросы к Ollama по адресу localhost остаются на компьютере; при использовании удалённого провайдера текст отправляется ему.
- Backend принимает только текст, который клиент явно отправил. Само распознавание речи браузером может использовать отдельный сервис браузера.
- История ограничена восемью короткими репликами; лишние поля личности отбрасываются.
- Ответ модели валидируется; неизвестные действия и эмоции отклоняются.
- CORS по умолчанию разрешает только localhost. Для публичного размещения нужны HTTPS, аутентификация, rate limiting и политика хранения данных.
