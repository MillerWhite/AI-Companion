# AI Companion — Language Backend v1.1

Отдельный необязательный сервер для понимания свободной речи. Он не управляет экраном, динамиком, датчиками или прошивкой напрямую.

## Требования
- Python 3.10+
- Установленные зависимости из `requirements.txt`
- API-ключ и имя модели выбранного OpenAI-compatible провайдера (только если нужен реальный языковой ИИ)

## Запуск в Windows
Из корня репозитория:

```bat
py -m venv backend\.venv
backend\.venv\Scripts\activate
py -m pip install -r backend\requirements.txt
copy backend\.env.example backend\.env
```

Заполните `AI_API_KEY` и `AI_MODEL` в `backend\.env`. Не публикуйте этот файл и не вставляйте ключ в HTML.

Запуск сервера из корня репозитория:

```bat
uvicorn backend.main:app --host 127.0.0.1 --port 8787
```

Проверка: откройте `http://127.0.0.1:8787/health`.

## API

`POST /api/interpret`

Пример запроса:

```json
{
  "utterance": "Мне сегодня грустно, побудь рядом",
  "companion_name": "Мило",
  "personality": {"temperament": "gentle", "initiative": "medium"},
  "recent_context": [{"role": "owner", "text": "Привет"}]
}
```

Сервер возвращает ограниченный JSON с `intent`, `action`, `emotion`, `confidence`, `nonverbal_cue` и необязательным `clarification`. Действия и эмоции проверяются по allowlist. Клиент обязан дополнительно проверить ответ и сопоставить его со своими локальными реакциями.

## Режим без API-ключа
Сервер запускается и отвечает на `/health`, но `/api/interpret` возвращает `503 ai_not_configured`. Это намеренно: backend не имитирует работу языковой модели. В браузерном прототипе v1.0 локальный разбор команд остаётся основным fallback.

## Приватность и безопасность
- Микрофон и распознавание речи остаются на стороне браузерного прототипа. Backend принимает только текст, который клиент явно отправил.
- Не отправляйте текст в облако без отдельного согласия владельца.
- API-ключ хранится только в переменных окружения backend.
- Переданные личностные данные фильтруются по allowlist; история ограничена восемью короткими репликами.
- CORS по умолчанию разрешает только localhost origins; для другого домена задайте `AI_ALLOWED_ORIGINS`.
- Ответ модели валидируется. Неизвестные действия/эмоции отклоняются.
- Это первый серверный каркас, а не готовый production-сервис: перед публичным размещением нужны HTTPS, аутентификация устройства/владельца, rate limiting, лимиты расходов и политика хранения данных.
