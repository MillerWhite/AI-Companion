# AI Companion — Cloud Language Backend v1.3

Облачный языковой модуль на базе Google Gemini API. У Gemini есть бесплатный уровень для ряда моделей, но квоты RPM/TPM/RPD ограничены и могут меняться. Безлимит не обещается.

## Получить бесплатный Gemini API key

1. Откройте https://aistudio.google.com/app/apikey
2. Создайте API key для проекта Free Tier.
3. Не включайте платный тариф и не привязывайте биллинг, если не хотите расходов.
4. Секретный ключ добавьте только в переменные окружения backend. Никогда не помещайте его в HTML, JavaScript сайта, прошивку или публичный GitHub.

Важно: условия Free Tier могут разрешать Google использовать переданные данные для улучшения продуктов. Не отправляйте конфиденциальные данные владельца без отдельного согласия.

## Конфигурация

Скопируйте backend/.env.example в backend/.env и задайте AI_API_KEY. Остальные значения уже настроены:

- AI_PROVIDER=gemini
- AI_API_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai
- AI_MODEL=gemini-3.6-flash

Backend использует OpenAI-compatible endpoint Gemini. Ключ хранится только на сервере.

## Локальный запуск backend для разработки

Требуется Python 3.10+.

```powershell
py -m venv backend\.venv
backend\.venv\Scripts\Activate.ps1
py -m pip install -r backend\requirements.txt
Copy-Item backend\.env.example backend\.env
uvicorn backend.main:app --host 127.0.0.1 --port 8787
```

Проверка: http://127.0.0.1:8787/health

## Архитектура с Waveshare

ESP32-S3 не запускает Gemini и не содержит API key. Прошивка локально выполняет отрисовку 466×466, анимации глаз/рта, касания, датчики, аудио и базовые реакции. При необходимости устройство отправляет короткий распознанный текст или событие на наш HTTPS backend; backend вызывает Gemini и возвращает только проверенное JSON-намерение (эмоция/действие/уверенность). Прошивка проверяет ответ и применяет его через локальный движок. При отсутствии Wi-Fi или исчерпании бесплатной квоты устройство продолжает работать автономно.

## Сайт и прошивка

Сайт будет использовать Web Serial/WebUSB для передачи прошивки на плату через USB в поддерживаемом браузере. AI backend — отдельный облачный сервис, а не часть HTML и не часть бинарной прошивки. Конфигурация устройства будет содержать только публичный адрес backend и уникальный идентификатор устройства; секреты провайдера остаются на сервере. Для массового запуска потребуются HTTPS, аутентификация устройств, лимиты на устройство, защита от злоупотреблений и мониторинг квот.

## Приватность и ограничения

- Gemini Free Tier имеет ограничения RPM/TPM/RPD; они зависят от модели и проекта и могут изменяться.
- В Free Tier Google может использовать переданные данные для улучшения продуктов Google; проверьте актуальные условия перед реальным запуском.
- Передача распознанной речи в облако должна быть отдельной, понятной и отключаемой настройкой владельца.
- Не храните API key в браузере, прошивке или репозитории.
- Если API недоступен, устройство использует локальную логику без блокировки экрана, анимаций и звуков.
